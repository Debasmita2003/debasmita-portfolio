## 💻 Installation

Clone the repository:

```bash
git clone https://github.com/Debasmita2003/debasmita-portfolio.git
```

Navigate to the project folder:

```bash
cd debasmita-portfolio
```

Install dependencies:

```bash
npm install
```

Start development server:

```bash
npm run dev
```
